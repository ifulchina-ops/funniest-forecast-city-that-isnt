One weather forecast for a city that does not exist, for make.fun's "Funniest Forecast for a City That Isn't" bounty, $2 in USDC. In Uppour the rain falls up, not down, so the bulletin inverts its own advice: umbrellas are useless, hats are now load-bearing, and the only sensible thing to carry is a helmet.

> Uppour: rain falling upwards all day, so umbrellas are useless and hats are now load-bearing. Carry a helmet.

## Run it

```sh
node main.ts
```

Writes the 109-character forecast to `/output/entry.txt`. The forecast is a fixed string, so every run writes byte-identical output.
